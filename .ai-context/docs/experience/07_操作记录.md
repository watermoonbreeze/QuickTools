# 操作记录

## [2026-08-14] 排查并修复 Gradle Daemon JVM 校验导致的编译失败

- 起因：用户此前多次会话提到 IntelliJ 编译报错，一直没贴出报错原文，本次要求 AI 直接编译复现。
- 执行 `./gradlew.bat compileKotlinJvm --console=plain` 复现报错：`Unable to download toolchain ... vendor=Azul Zulu ... api.foojay.io ...`。
- 排查确认：本机已装 JDK 21（`C:\Program Files\Java\jdk-21`），但厂商是 Oracle，不满足 `gradle/gradle-daemon-jvm.properties` 里 `toolchainVendor=AZUL` 的硬性要求，触发 `foojay-resolver-convention` 插件联网下载，联网失败导致构建中止。
- 修复：`Edit gradle/gradle-daemon-jvm.properties`，删除 `toolchainVendor=AZUL` 一行，仅保留 `toolchainVersion=21`。
- 验证：重新执行 `./gradlew.bat compileKotlinJvm` → `BUILD SUCCESSFUL in 2m 7s`。
- 该文件此前未被 git track（整个 `gradle/` 目录在 untracked 列表里），改动会随本次 commit 一起进仓库，不涉及历史改写。
- 详见方法论：[06_问题与踩坑.md](06_问题与踩坑.md)。
